## 当前需要知道的上下文

- **跨盘复制三段式**：取链 → 分段下载（16MB 一段、串行）→ 秒传探测 / 分片上传。任务全局并发默认 2（`CROSS_COPY_MAX_CONCURRENT`，硬上限 8），文件夹任务内部逐文件串行。
- **秒传的前提是目标端的哈希体系**：115 用 SHA1（大写）、夸克要 md5+sha1（**都小写**）、阿里要 `content_hash`。115 只给 SHA1，所以 **115 → 夸克/阿里 一定会下载一遍**（为了算 md5 / pre_hash），命中只是省掉上传。
- **直链是签名 URL，取到什么样就请求什么样**：`normalize_http_url` 只编码非 ASCII，不碰已有转义（改一个字节签名就失配 403）；夸克 `update/hash` 的 md5/sha1 必须小写。这两条都是真机炸出来的。
- **任务记录可以清**：批量（已完成 / 失败 / 已结束）+ 单条删除，只删记录、不删网盘文件；另有按条数保留的自动裁剪兜底。
- **115 直链按 UA 签名**，取链与下载必须共用同一套请求头，细节见 `docs/superpowers/specs/2026-10-20-115-direct-link-user-agent-binding.md`。
- 接收夹是**可选中转入口**，与网盘无关（每个网盘一个），分发目标必须同盘；自动整理只有「接收夹」和「订阅」两个入口，文件夹监控是纯扫描。
- **功能模块索引**：`docs/superpowers/modules.md`，新增或改名路由 / 服务 / provider / 页面必须登记（`tests/test_modules_doc.py` 会校验）。
